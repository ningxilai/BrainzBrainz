* musicbrainz — MusicBrainz terminal client

Query the MusicBrainz API from the terminal. Human-readable output by
default, =--json= for scripts. Zero dependencies besides =curl= and a
C++20 compiler (JSON via vendored [[https://github.com/nlohmann/json][nlohmann/json]]).

** Build

#+begin_src sh
  make          # builds ./musicbrainz and ./bookbrainz
  make clean
#+end_src

** Use

#+begin_src sh
  musicbrainz search artist --query "artist:radiohead"
  musicbrainz lookup release 4b3d18cc-8937-36f4-8de0-481088be58e6
  musicbrainz browse release --artist a74b1b7f-71a5-4011-9441-d0b5e4122711
  musicbrainz query --entity artist --param query=artist:radiohead
#+end_src

Append =--json= to any of the above for machine-readable output.
Run with no arguments (or =--help=) for the full synopsis.

One request per second max, per MusicBrainz rate-limit policy.

* bookbrainz — BookBrainz terminal client

Same shape, against =api.bookbrainz.org= (entities: author edition
edition-group publisher series work).

#+begin_src sh
  bookbrainz search author --query "Tolkien"
  bookbrainz lookup edition 2c389e5c-cf78-449e-9f9e-a5f7840b085b
  bookbrainz browse edition --author d0ac6e1f-617d-41a7-928a-26bb401f77ad
  bookbrainz query search --param q=Dune --param type=edition
#+end_src

Search takes =--query= (+ =--limit= / =--offset=); lookup takes an MBID;
browse takes exactly one =--<linked>= MBID. =--json= and the rate
policy behave as above.
